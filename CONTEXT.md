# Domain glossary

- **Observation:** A provider's numeric player trade value at the time it was captured.
- **Snapshot:** One atomic collection of observations from a source and valuation context.
- **Valuation context:** The provider's league/scoring/settings configuration. Changing it begins a separate series.
- **Cost basis:** The manually recorded value invested in an acquisition, expressed in the chosen source and context.
- **Acquisition lot:** One purchase/receipt of a player. Reacquisition creates a separate lot.
- **Unrealized ROI:** `(latest value - cost basis) / cost basis * 100` for a positive cost basis.
- **Target reached:** The current observed value meets the lot's target. It is an exit consideration, not a completed profit.
- **Realized return:** Exit proceeds minus cost basis after an exit is explicitly recorded.
- **Mapping:** A confirmed relationship between a provider player ID and a canonical player. Similar names alone do not prove identity.
